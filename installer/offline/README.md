# Offline AI content (optional release build)

The ordinary installer works without system Node.js or Yarn, and offers Online/Hybrid
mode. To produce a genuinely offline AI installer, include the *licensed*, approved
Ollama Windows executable and its PRE-DOWNLOADED model data in the release build:

    installer/offline/ollama/ollama.exe
    installer/offline/models/{blobs,manifests}/...
    installer/offline/bundle-manifest.json

The bundle manifest is generated by `installer/windows/prepare-offline-bundle.ps1`
from these inputs. Do not commit model weights or redistributable binaries to Git.
Bundled AI requires substantial disk space and model redistribution permission.
The installed app reads models directly from the bundled resources without
calling any external service. Local AI initialization may take time on first launch.
