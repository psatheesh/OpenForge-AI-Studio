    ENVIRONMENT

    Runtime & Model Configuration

    Online and local AI settings are configured using server environment variables; API credentials never enter the browser's project files.

    ▣ Offline inference

    Install Ollama and download a coding model before disconnecting from the network.

    ollama pull qwen2.5-coder:7b
set OLLAMA_MODEL=qwen2.5-coder:7b
    Windows: use set; Linux/macOS: use export.

    ☁ Cloud inference

    Configure an OpenAI-compatible chat completions endpoint through environment variables.

    AI_BASE_URL=https://YOUR_PROVIDER/v1/chat/completions
AI_MODEL=YOUR_MODEL
AI_API_KEY=YOUR_SECRET
    Do not commit credentials to Git.

    ◈ Hybrid fallback

    Hybrid uses the cloud endpoint when one is configured; otherwise it uses the local Ollama endpoint. Local editing and project access remain available without connectivity.
